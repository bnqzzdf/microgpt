The Missing Half: How a GPT Learns

Karpathy's original program is one continuous loop: predict every next token, measure how wrong the predictions are, send that error backward through every operation, and update the parameters that influenced the example.

This lab uses fresh random weights, separate from the pretrained model in the other tabs. Repeating one name intentionally overfits it so the learning mechanism is easy to see.

Autoregressive Generation — How GPT Creates New Text

The model generates names one token at a time. It starts with <BOS>, predicts the next token, feeds it back as input, and repeats until it predicts <BOS> again (end of name). This is called autoregressive generation — the same process ChatGPT uses to write responses.

Temperature controls randomness: low (0.1) = sharper, more repetitive; high (1.5) = flatter, more random. Positive temperatures still use random sampling. T=0 greedy decoding needs separate handling; this interface uses T≥0.1.

How Attention Works — Q, K, V & Multi-Head

Each token projects itself into three vectors: Query ("what am I looking for?"), Key ("what do I contain?"), and Value ("what do I offer if selected?"). Query–Key dot products are scaled and normalized with softmax into attention weights; these weights then blend the Values.

4 heads can learn different patterns. The colors show measured attention weights; do not assign a meaning such as “vowel head” unless the examples actually support it. The matrix shows causal attention — each row only sees itself and previous rows (no looking into the future). Blue = low attention, red = high.

Glossary — Key Concepts Explained
<BOS> Beginning of Sequence — a special token that marks the start and end of a document. The model learns that BOS means "start a new name" and another BOS means "the name is complete."
Tokenizer Converts text ↔ integers. This model uses a character-level tokenizer: each letter a-z gets a unique ID (0-25), and BOS = 26. Production models use subword tokenizers (BPE) with ~100K tokens.
Embedding A lookup table that maps each token ID to a learned 16-dimensional vector. Training changes these coordinates whenever that token contributes to an error; the vector is learned internal state, not a human-readable definition.
Position Embedding Adds a learned vector based on the token's position in the sequence (0, 1, 2...). This tells the model where each token is, since attention alone has no notion of order.
RMSNorm Root Mean Square Normalization — rescales the vector so its values have unit RMS. This stabilizes training by preventing activations from growing or shrinking as they flow through layers.
Attention (Q, K, V) Query "what am I looking for?", Key "what do I contain?", Value "what do I offer?" — scaled Q–Key dot products pass through softmax to become attention weights, which blend the Values. This is where positions exchange information.
Multi-Head Attention Runs 4 attention operations in parallel, each on a 4-dimensional slice. Heads can learn different patterns, but a semantic role such as “vowel detector” must be demonstrated from measurements rather than assumed.
KV Cache Stores Keys and Values from all previous positions so they don't need to be recomputed. The new query attends to all cached keys. Size grows by one at each step.
MLP Multi-Layer Perceptron — a per-token "thinking" step: project from 16→64 dimensions, apply ReLU, project back to 16. Unlike attention, MLP processes each position independently.
Residual Connection Adds the block's input to its output (x = block(x) + x). This lets gradients flow directly through the network, making deeper models trainable. Both attention and MLP blocks use this.
Softmax Converts a vector of raw scores (logits, ranging -∞ to +∞) into a probability distribution that sums to 1. The highest logit gets the most probability, but not 100% — other choices remain possible.
Logits The raw output scores from the model, one per vocabulary token. Higher logit = the model thinks that token is more likely. Softmax converts these to probabilities.
Cross-Entropy Loss Measures "how surprised" the model is by the actual next token: -log(predicted_prob_of_correct_token). Loss = 0 means perfect prediction; loss = 3.3 ≈ random guessing among 27 tokens.
Temperature Divides logits by T before softmax. Low positive T sharpens the distribution but does not guarantee the top token. High T flattens it. T=0 greedy decoding requires a separate argmax branch, not division by zero.
Autoregressive The model feeds its own output token back as the next input. Like writing a letter: each new word depends on everything written so far. This is how all GPT models generate text.
Autograd / Backprop Automatic differentiation via the chain rule. The Value class tracks every operation, building a graph. backward() walks the graph in reverse, computing how each parameter affects the loss.
Adam Optimizer Adam maintains per-parameter momentum (smooths gradient direction) and adaptive learning rates (scales down frequently-updated parameters). It's the standard optimizer for training neural networks.
