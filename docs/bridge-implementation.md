# “从模型到助手”实施记录

日期：2026-10-17。依据：[Astra 方案](model-to-assistant-plan.md)。

## 已落地范围

实施的是 P0/P1 的离线教学功能，不是 P2 的真实聊天模型接入。基础六关与四沙盒保留，主导航和第六关回顾新增进阶入口。仍是普通 JavaScript + 静态文件，无新增安装依赖、后端、密钥或外部推理请求。

- A：气泡 → 消息字段 → `teaching-chat-v1` 序列 → 教学 token；消息/字段和序列/token 联动高亮；历史显式排除；预算显式报错；实际执行输入证据检查。
- B：独立名字模型和 KV；权重加载、提示准备、逐位置 prefill、首输出复用、decode、停止；真实概率和采样随机数；独立空缓存重算对照；固定种子及参数快照检查；单步/自动/暂停/取消。
- C：预训练、后训练和固定权重执行的能力来源卡；四个预设案例；最终答案、算术等式、符合题意三者分开检查；不运行语言模型裁判，不用任意字符串执行。
- 九道可重试/跳过的理解题、独立进度、损坏/禁用存储降级、明确的刷新重置说明、中英界面、可单独载入的中英文教材、本地 JSON 导出。

真实性说明：教材由本项目在 AI 辅助下编写，界面标记“预设教材 · 非模型实测”，不冒称人类作者的实测记录。A 的 Unicode 码点教学词表与 B 的 27-token 真实名字模型完全隔离。只有 B 展示真实 GPT 概率，C 的结果来自普通确定性程序。`BridgeCore.offlineAdapter()` 是不会发送数据的禁用契约，不是已配置的语言模型适配器。

## 文件边界

| 文件 | 职责 |
| --- | --- |
| `data/bridge-scenarios.js` | 版本化教材、理解题、中英说明；由主 I18n 载入统一翻译表 |
| `js/bridge-core.js` | 消息验证与序列/偏移变换、预算、证据、判题、进度清洗、禁用适配器 |
| `js/bridge-runner.js` | 独立模型推断、版本化 RNG、事件、缓存对照和结果快照 |
| `js/bridge-course.js` | 视图、交互、临时实验状态、独立持久进度和本地导出 |
| `css/bridge.css` | 来源标签、单列窄屏、表格滚动容器、焦点与减少动态效果支持 |
| `tests/bridge-checks.cjs` | 新功能的无依赖验证 |

原文件仅作必要接入：`index.html` 新资源和容器，`js/app.js` 初始化/页面分派，`js/course.js` 回顾入口，`js/i18n.js` 接纳教材词条，既有双语测试加载新文案。没有改动模型数学、训练器和已有采样算法。

## 数据与可复现边界

- 本篇进度键为 `microgpt.bridge.v1`，不写入输入、轨迹、权重或教材结果。语言沿用原语言键；本篇重置不清基础课或沙盒。
- 导出是用户主动的本地下载，含场景/题集版本、输入快照、教学表示、权重指纹、配置、逐步事件和来源限制。没有遥测或远程存储。
- 指纹明确标注 FNV-1a 32-bit、非密码学用途，不冒称安全校验和。RNG 固定为 `lcg32-v1`；记录每次采样随机数。跨引擎浮点差异仍可能在边界改变采样，不承诺跨硬件逐比特一致。
- 运行期间设置只在明确重置后生效；无效配置不会取消已有运行。翻译、查看结果和导出不调用前向、不消耗 RNG。
- 缓存对照创建相同权重的独立空缓存重算当前已处理序列，不替换当前运行的缓存。对照调用次数单列，主运行计数不混入对照。
- 每步教学播放间隔仅供观看，不计作模型延迟。首版不显示真实聊天模型的 token 费用、推理增益或隐藏思维数据。

## 验证记录

自动化命令：

```powershell
node tests/model-checks.cjs
node tests/i18n-checks.cjs
node tests/bridge-checks.cjs
```

三组检查通过。新增检查包含 Unicode/emoji 的 UTF-16 偏移、保留标记与非法角色、历史筛选和不截断、独立进度清洗/损坏/禁用、prefill 与首输出复用、KV 重算与 RNG 不变、权重/旧模型隔离、预算和停止、各类题目判定、全部进阶双语词条、初始化/导出无计算及无网络路径。

页面检查已覆盖：A 历史排除、键盘空格操作及答题后中英切换；B 真实首输出、缓存重算与中英数值保留、设置应用、自动推进到输出预算停止、取消；C 错误步骤/题意不符判定和反馈双语；本地 JSON 下载；刷新恢复章节且清空实验；320px 和 390px 的中英视图；新页面无脚本错误。原六关回顾的桥接入口可用，原预测步进、单步训练（3.512 → 3.050）、生成 20 个名字及注意力页面已做回归。

## 发布前仍需人工验收

本轮代码与自动化验证完成不等于 Astra 方案中所有发布门槛均已完成：

- 由至少 5 位目标读者走查是否仍误认为“名字模型回答中文”或“预设案例是模型实测”。
- 使用实际屏幕阅读器走查播报、焦点与操作体验；已提供语义化控件/状态/标签，但 AX 结构检查不替代此项。
- 200% 桌面缩放与不同浏览器的视觉/交互走查。
- 如要接入真实聊天模型，先决定运行位置、模型与 tokenizer/template 版本、数据规则、硬件或费用及部署责任，再实施 P2 的受控实验。当前不能点击一个隐藏开关就启用外部模型。

不以分步解答表现更好作为发布条件，也不将四个教材案例计算成模型正确率。
